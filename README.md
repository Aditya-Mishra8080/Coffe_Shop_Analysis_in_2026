# ☕ Coffee Shop Analysis 2026 (Excel Project)

## 📌 Project Overview
This is a **Mini Project** created using **Microsoft Excel** for analyzing sales data of a Coffee Shop in 2026.  
The project highlights how to use **Pivot Tables and Charts** to gain insights into sales performance without using any external APIs or programming languages.

---

## 📊 Dataset Details
- File: `Coffee Shop Analysis 2026.xlsx`
- Includes:
  - **Category-wise Sales** (Bakery, Beverage, Coffee, Food)
  - **Monthly Sales** (Jan–Oct 2026)
  - **Store Performance** (Delhi, Lucknow, Mumbai)
  - **Quantity Sold** per category
  - **Top Selling Products** (Brownie, Muffin, Mocha, Latte, etc.)
  - **Detailed Transaction Data** (Date, Product, Category, Qty, Unit Price, Store, Total Sales)

---

## 🛠️ Tools & Techniques
- **Microsoft Excel**
  - Pivot Tables
  - Pivot Charts
  - Data Filtering & Sorting
  - Basic Formulas (SUM, COUNT, etc.)
- **GitHub** → For project hosting and sharing

---

## 📈 Key Insights
- Coffee category generated the highest sales: `2210`
- Delhi store performed best with total sales: `1840`
- Mocha (`680`) and Muffin (`640`) were top-selling items
- September (`680`) and October (`790`) had peak monthly sales
